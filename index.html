    01 INTELLIGENCE, ENGINEERED.

    INTELLIGENCE,
    ENGINEERED.

    Artificial intelligence is not a single invention, and it is not a machine that thinks like you. It is a way of building software that improves by finding patterns in examples instead of following rules written by hand.

    A programmer writes the rules. The computer applies them, exactly, to every input.

    1. 01Inputs arrive
    2. 02Rules are applied
    3. 03An output is produced
    TRADITIONAL INPUT + RULES → OUTPUT
    FIELD

    Artificial intelligence

    The broad discipline of making computers perform tasks that normally require human intelligence — recognising a face, translating a sentence, choosing a move.

    SUBSET

    Machine learning

    Instead of writing rules, we show a program thousands of examples. It adjusts internal numbers until its answers match the examples. Nobody writes the rule; the rule is discovered.

    SUBSET OF A SUBSET

    Deep learning

    Machine learning with neural networks of many layers. Early layers learn simple features like edges; deeper layers combine them into shapes, objects and concepts.

        04 LEARNING, FOR REAL

        HOW DOES A
        MACHINE LEARN?

        It guesses. It measures how wrong the guess was. It adjusts every weight a little in the direction that reduces the error. Then it does it again — hundreds of thousands of times.

        1. 01FORWARD PASSData flows in, predictions come out.
        2. 02LOSSOne number for “how wrong”.
        3. 03BACKPROPAGATIONTrace each weight's share of the blame.
        4. 04UPDATENudge weights downhill. Repeat.

        This loop is the whole of deep learning. Scale it up and you get a language model; it is the same four steps, thousands of billions of times.

        WHAT YOU JUST BROKE, AND WHY

        Set the learning rate too high and the loss climbs instead of falling: each step is so large that it jumps across the valley rather than into it. Set it too low and progress crawls. This balance — and thousands of small decisions like it — is what machine learning engineers actually tune.

        05 LARGE LANGUAGE MODELS

        FROM WORDS TO TOKENS.
        FROM TOKENS TO RESPONSES.

        A chatbot never sees your words. It sees numbers. Your sentence is cut into fragments, turned into vectors, passed through attention layers — and the only thing the model ever does is guess the next fragment.

        TOKENS EMBEDDINGS ATTENTION NEXT TOKEN
        01

        SPLIT INTO TOKENS

        Text is broken into sub-word pieces. Common words stay whole; rare words split. Each piece has an ID in a fixed vocabulary.

        02

        EACH TOKEN BECOMES A VECTOR

        Every ID maps to a list of numbers — the embedding. Meaning becomes geometry: tokens used in similar contexts end up near each other.

        Shown with 8 dimensions for legibility. Real models use 4 096 or more, and the values are learned, not hashed.

        03

        ATTENTION: WHO IS LOOKING AT WHOM

        Inside a transformer, each token asks a question (a query), every token offers an answer key, and the best matches pass their information forward. A causal mask stops tokens from reading the future.

        FOCUS

        Hover a row to see where that token looks.

        Attention = softmax( QKᵀ / √d ) V
        Q: what I'm looking for · K: what I offer · V: what I pass on

        The grid is an illustrative self-attention map computed from token vectors and position — not the internal state of a production model.

        04

        GUESS THE NEXT TOKEN. THEN AGAIN.

        After 96 layers of attention and computation, the model produces a score for every token in its vocabulary. Those scores become probabilities. One token is chosen, appended, and the whole process repeats.

        SEQUENTIAL GENERATION

        A toy language model built from a small local word table. It predicts like a real one does — only far, far worse.

        TRAINING A LANGUAGE MODEL
        1. Pre-training. Predict the next token across an enormous body of text. This is where grammar, style and much of the world's recorded knowledge are absorbed.
        2. Fine-tuning. Train further on examples of instructions and good answers.
        3. Human feedback (RLHF). People rank competing answers; a reward model learns those preferences; the model is tuned toward what raters preferred.
        THE CONSEQUENCE NOBODY CAN ENGINEER AWAY

        Because the objective is plausible continuation, not truth, a language model can produce a sentence that reads like a citation and cites nothing. Fluency is not evidence. It was never designed to be.
